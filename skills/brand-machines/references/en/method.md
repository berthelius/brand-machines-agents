# The Brand Machines framework

An operational adaptation of Viktor Berthelius's canon and Chapters 11, 12, 17 and 23. English terminology follows the English book's canon and controlled glossary; it does not establish a different framework.

## Canonical definition

> Brand Machine: A generative identity system that produces coherence autonomously through principles, not fixed rules.

Operational definition from Chapter 3: a Brand Machine is an interconnected, modular, evolving system that integrates identity, narrative, technology, and intelligence to generate continuous coherence without constant manual intervention.

Its three structural properties are **Interconnected**, **Modular** and **Evolving**. Components communicate; they can be updated independently without breaking the system; and the system improves based on data and feedback. It is not marketing automation or a digitized brand manual.

## The seven layers

| Layer | Canonical definition | Components or function |
|---|---|---|
| 1. Core | The deepest layer. It is not what you say you are; it is what you are when no one is watching. | Purpose, actionable values, vision. It evolves over decades, not quarters. |
| 2. Mind | Distributed intelligence that makes coherent decisions without centralization. | Decision principles, cognitive frameworks, response patterns. |
| 3. Body | Modular architecture that structures expression. | Design system, components, tokens, variables. |
| 4. Skin | The brand's visible and sensory manifestation. | Visual, verbal, sonic and tactile identity. |
| 5. Engines | Generative systems that produce brand output. | Content Engine, Response Engine, Campaign Engine, Personalization Engine, Culture Engine. |
| 6. Brand OS | The operating system that orchestrates all layers. | Workflows, integrations, automations. |
| 7. Interconnections | APIs and points of contact with external ecosystems. | The brand as a platform, not an island. |

The layers describe a connected architecture, not seven independent boxes. Examine how a decision in one layer changes, constrains or informs another. Do not equate a layer with a particular tool.

## The five ontologies

These are overlapping ways of understanding a brand, not maturity stages: **Organism** (a living being that adapts), **Architecture** (a habitable structure), **Language** (a generative system of meaning), **Network** (a node of relationships), **Process** (a continuous flow). They do not replace the seven layers.

## Actionable values — Chapter 11, Section 11.3

A value has six fields: name, operational definition, situations that activate it, explicit trade-off, application example and counterexample. Its formulation must help decide what to do and what to discard. A value without a cost or observable behavior still needs to be made concrete.

When two values compete, use the explicit hierarchy, contextual hierarchy or meta-principle defined by the brand. If no criterion exists, show the conflict and request the relevant decision. Do not invent a hierarchy to make a real tension disappear.

## Guardian and memory — Chapter 12, Sections 12.2–12.4

The book distinguishes Generation, Research, Listening, Guardian and Personalization agents. Each function has relevant context, tools, success criteria and memory. This does not require launching five processes: separate functions only as the task requires.

The Guardian checks production against the Core and detects drift. Working memory supports the interaction; episodic memory retains decisions and results; semantic memory retains principles and versioned knowledge. Retrieve only what matters to the current decision.

## Interconnections and autonomy — Chapters 17 and 23

Chapter 17 presents validation as a service that returns issues and suggested corrections. This skill's local implementation covers deterministic checks; semantic judgment belongs to the agent applying the method with its sources.

Autonomy in Chapter 23 is gradual. A coherence judgment does not by itself authorize publication or identity changes. Uncertain data remains uncertain; it does not become a commercial promise.

## Protected vocabulary

Use Brand Machine, Core, Mind, Body, Skin, Engines, Brand OS and Interconnections. Emergent coherence does not mean uniformity or consistency. An Engine is not a synonym for a tool. A Brand OS is not a brand manual. The reference pack's visual and voice preferences are not requirements for all brands.

Spanish equivalents, in the same order: Núcleo, Mente, Cuerpo, Piel, Motores, Brand OS, Interconexiones. Use actionable values for valores operables and coherence for coherencia.
